How a document is assembled

Each section file carries a metadata comment, an optional <!-- peek --> block shown while the section is closed, and a <!-- body --> block shown when it opens. The build script wraps them in the section chrome, so a section file contains only content.

<!--
id: architecture
label: Architecture
summary: One or two sentences, shown while the section is closed.
-->
<!-- peek -->
  ...the one diagram that makes this section worth opening...
<!-- body -->
  ...the open markup...

Use the peek well. It is the only part most readers see. Put the section's key diagram, table or set of chips there, not a restatement of the summary line.
